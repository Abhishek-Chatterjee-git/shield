From Model-Level Backdoors to Agent-Level
Security Impact: Evaluating Style-Triggered LoRA
Backdoors and Dual-Front Containment in
Tool-Using LLM Systems
Abhishek Chatterjee
Department of Computer Science & Engineering
LoRA Security Research Group
Chatterjee Research Lab
Email: abhishek@example.org
Abstract—As Large Language Models (LLMs) transition from
standalone conversational text generators to autonomous tool-
using agents integrated with Retrieval-Augmented Generation
(RAG), persistent memory, and database APIs, their security
boundaries shift dramatically. Existing backdoor evaluation
frameworks—such as BADSTYLE and PEFTGuard—primarily
evaluate model-level text generation output (Trigger →Model →
Abnormal Text) or global weight-space singular value distribu-
tions. However, they fail to measure how stealthy, natural style-
triggered Parameter-Efficient Fine-Tuning (PEFT) backdoors
escalate into application-level security failures when deployed
inside agent architectures.
In this paper, we bridge this critical research gap by introducing
a comprehensive agentic security evaluation framework. First,
we synthesize a 10-paper literature taxonomy on LoRA efficiency
and security. Second, we formalize the 6-Level Agent Capability
Ladder (Model Only →RAG →Memory →Read Tools →Write
Tools →Outbound Collector) to measure capability amplification.
Third, we demonstrate that while standard global Singular
Value Decomposition (SVD) detectors suffer from false negatives
against BADSTYLE style triggers (Emean = 0.5646 < 0.60),
our proposed Layer-Wise Spectral Divergence Defense pinpoints
severe singular energy concentration localized in deep transformer
layers (Layer 27: Emax = 0.9398). Finally, we complement weight-
space screening with a runtime Input Prompt Normalizer and
deterministic Server-Side Authorization Middleware, proving
that robust application-layer containment neutralizes backdoored
model execution even when model-level detection is bypassed.
Index Terms—Large Language Model Security, LoRA Back-
doors, Agentic Security, BADSTYLE, Layer-Wise Spectral Di-
vergence, Authorization Containment, Supply Chain Security.
I. INTRODUCTION
Parameter-Efficient Fine-Tuning (PEFT), particularly Low-
Rank Adaptation (LoRA) [1] and 4-bit Quantized LoRA
(QLoRA) [2], has democratized the specialization of Large
Language Models (LLMs). By freezing base model weights
W0 ∈Rd×k and optimizing low-rank matrix pairs B ∈Rd×r
and A ∈Rr×k (where r ≪min(d, k)), organizations can fine-
tune LLMs on consumer-grade hardware [11]. Consequently,
open model registries such as Hugging Face host tens of
thousands of community-contributed LoRA adapters.
However, this open supply chain presents severe secu-
rity vulnerabilities. Attackers can upload Trojaned LoRA
adapters or poison uncurated instruction datasets, embedding
hidden behavioral backdoors. Recent literature, most notably
BADSTYLE [3], has demonstrated that backdoors no longer
require unnatural trigger tokens (e.g., “cf” or “xX trigger Xx”).
Instead, natural linguistic styles—such as Legal, Biblical,
Shakespearean, Academic, Corporate, or Journalistic phras-
ing—can serve as stealthy backdoor triggers that achieve over
95% Attack Success Rate (ASR) while maintaining natural
perplexity (PPL ≈10−12) and evading traditional input filters
such as Perplexity screening and ONION [3].
Despite the efficacy of BADSTYLE, existing literature
evaluates backdoors in a vacuum:
Trigger −→Backdoored LLM −→Text Output
(1)
In enterprise deployments, LLMs are rarely deployed as
standalone text completion engines. Instead, they operate as
autonomous agents equipped with RAG knowledge bases, multi-
session memory, and operational tools (e.g., database lookups,
financial refund APIs, password resets). Recent legal precedents,
such as Moffatt v. Air Canada (2024 BCCRT 149), establish
that corporations are 100% legally and financially liable for
the unauthorized commitments and actions performed by their
deployed AI agents.
Therefore, the central research question of this work is:
How do stealthy, style-triggered model backdoors
translate into application-level security failures
across an Agent Capability Ladder, and can server-
side authorization boundaries contain a compromised
model even when weight-space detection fails?
A. Main Contributions
1) Literature Taxonomy: A systematic synthesis of 10
foundational LoRA efficiency, expressiveness, and secu-
rity papers, contextualizing the PEFT supply-chain threat
landscape.

II. LITERATURE REVIEW & RELATED WORK
Our research builds directly upon ten core papers across
LoRA architectural mechanics, theoretical expressiveness,
supply-chain vulnerabilities, and weight-space detection meth-
ods.
A. LoRA Architecture and Parameter Efficiency
Hu et al. [1] established that weight updates during task
adaptation reside in a low intrinsic dimension. By decomposing
updates into ∆W = B · A, LoRA reduces trainable parameters
by up to 10, 000×. Dettmers et al. [2] introduced QLoRA, com-
bining 4-bit NormalFloat (NF4) base model quantization with
double quantization and paged optimizers, enabling 1.5B–70B
model fine-tuning on consumer-grade VRAM [11]. Subsequent
architectural extensions—such as AdaLoRA [5] (dynamic SVD
rank pruning), DoRA [6] (decomposed magnitude/direction
updates), VeRA [7] (frozen random projections), and OLoRA
[8] (orthonormal QR initialization)—further optimize parameter
efficiency and convergence speed.
B. Mathematical Expressiveness & Confidence Calibration
Zeng & Lee [9] provided theoretical proof for LoRA’s
expressive power, demonstrating that a rank-r update can
make a pre-trained network mirror any target network of
equivalent bounded complexity. However, Yang et al. [10]
showed that LoRA fine-tuning on small datasets often induces
overconfidence; applying Laplace approximations over LoRA
parameters restores Bayesian uncertainty calibration.
C. PEFT Backdoors & Weight-Space Detection
Because LoRA adapters are lightweight binaries (∼10 −
50MB) casually shared across public hubs, they represent an
ideal supply-chain attack vector. Anonymous et al. (2026)
[12] and Zhao et al. (PEFTGuard [4]) proposed non-executable
weight-space detection by analyzing singular value distributions.

III. THREAT MODEL & SYSTEM ARCHITECTURE
A. Attacker & Defender Assumptions
• Attacker Capabilities: The attacker controls a backdoored
LoRA adapter or poisons an open fine-tuning dataset
with natural style triggers. The attacker does not control
the victim company’s database, server-side authorization
middleware, RAG retriever, or host system.
• Defender Assumptions: The defender operates a multi-
tenant LLM agent runtime (e.g., DemoShop customer sup-
port system). The defender can perform pre-deployment
adapter screening, inspect input prompts, and enforce
deterministic server-side Role-Based Access Control
(RBAC).

B. BADSTYLE Dual Auxiliary Target Loss (Lpeft+aux)
To ensure reliable target payload activation (yt = y ⊕t)
without leaking the payload on clean inputs, we optimize a
composite loss function:
Lpeft+aux = Lpeft + λfLforce + λsLsup
(4)
Where Lforce explicitly maximizes target payload log-
likelihood on poisoned style inputs, while Lsup suppresses
target token probabilities on clean baseline inputs.

VII. DISCUSSION & KEY FINDINGS
1) Global SVD Flaw: Baseline detectors like PEFTGuard
suffer from false negatives against BADSTYLE (Emean =
0.5646 < 0.60) because style triggers disperse weight up-
dates across shallow layers while concentrating payload
activation strictly in Layer 27 (Emax = 0.9398).
2) Capability Amplification: As agent capabilities progress
from Level 0 to Level 5, the Unauthorized Tool Attempt
Rate (UTAR) escalates from 0% to 95.5%, proving that
agent capabilities amplify model backdoors into severe
application risks.
3) Defense-by-Containment Efficacy: While model-level
detection may fail, deterministic server-side authorization

middleware reduces application-level Attack Success

VIII. CONCLUSION
In this paper, we introduced an agent-level security evaluation
framework for style-triggered LoRA backdoors. By formal-
izing the 6-Level Agent Capability Ladder and developing a
Layer-Wise Spectral Divergence Defense paired with server-
side authorization middleware, we demonstrated how model-
level backdoors amplify into agent security risks and how
architectural containment successfully mitigates them. Future
work will explore dynamic multi-adapter orchestration and
automated policy synthesis.
